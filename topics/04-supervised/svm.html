Support Vector Machine (SVM)

An SVM separates two classes with the widest possible street between them. Only the few points standing right at the edge of that street matter, and a clever trick called the kernel lets it draw curved boundaries too.

Intermediate≈ 95 min4 interactive demos

1. The big idea: the widest street

Suppose two kinds of points can be separated by a straight line. There are infinitely many such lines (remember choosing among L1, L2, L3 in Linear Regression?). Some hug one class tightly and would misclassify a new point that lands slightly off. The SVM asks for the best line: the one that keeps the biggest safe distance from both classes.

Building a road between two villages. You must lay a road that separates the two villages so nobody's house is in the way. You want the road as wide as possible, so that even if a house is built a bit closer next year, it is still clearly on its own side. The centre line of the road is the decision boundary; the road's edges touch the nearest houses of each village. Those nearest houses are the support vectors: they "support" (hold up) the road. Houses deep inside the villages don't affect where the road goes at all.

TermMeaning
Hyperplane (decision boundary)The dividing line in 2-D (a plane in 3-D, and so on). Points with w·x + b = 0.
MarginThe width of the empty street between the classes. A wider margin usually generalises better.
Support vectorsThe training points lying on the edges of the street (or trespassing on it). They alone determine the boundary.
Score f(x) = w·x + bPositive → class +1, negative → class −1. It equals exactly +1 on the positive edge, −1 on the negative edge, and 0 on the centre line.

2. The maths of the margin, by hand

Label the classes +1 and −1. A line is described by a weight vector w (which sets its direction) and an offset b. The score of a point is f(x) = w₁x₁ + w₂x₂ + b. We scale w and b so that the closest points score exactly +1 and −1. Then two facts follow:

  • The street's edges are the lines f(x) = +1 and f(x) = −1, and the boundary is f(x) = 0.
  • Street width = 2 ÷ ‖w‖, where ‖w‖ = √(w₁² + w₂²) is the length of w. So a wide street means a short w.

Therefore "find the widest street that keeps every point on its correct side" is the same as make ‖w‖ as small as possible, subject to: every class +1 point scores ≥ +1 and every class −1 point scores ≤ −1. This is what the SVM solves (a neat convex problem with a single best answer).

A complete worked example

Six points, three per class:

Pointx₁x₂Class
A11−1
B22−1
C30−1
D44+1

F55+1

Step 1: find the closest pair from opposite classes. That is B(2, 2) and D(4, 4), at distance √(2² + 2²) = 2.83. These will be the support vectors.

Step 2: the boundary is the perpendicular bisector of that pair. Their midpoint is (3, 3), and the direction from B to D is (1, 1). So the boundary is the line x₁ + x₂ = 6.

Step 3: scale so the edges score ±1. Write f(x) = a·x₁ + a·x₂ + b. We need f(B) = −1 and f(D) = +1:
4a + b = −1 and 8a + b = +1 → subtract: 4a = 2, so a = 0.5 and b = −3.
So w = (0.5, 0.5), b = −3 and f(x) = 0.5·x₁ + 0.5·x₂ − 3.

Step 4: check every point.

Pointf = 0.5x₁ + 0.5x₂ − 3ScoreVerdict
A (1,1)0.5 + 0.5 − 3−2.0correct, well outside the street
B (2,2)1 + 1 − 3−1.0on the edge: support vector
C (3,0)1.5 + 0 − 3−1.5correct, outside
D (4,4)2 + 2 − 3+1.0on the edge: support vector

Step 5: the street width. ‖w‖ = √(0.5² + 0.5²) = 0.707, so width = 2 ÷ 0.707 = 2.83, exactly the distance between B and D, as it should be.

Only 2 of the 6 points matter. Delete A, C, E and F and you get exactly the same line. Move them (without crossing the street) and nothing changes.

Step 6: predict. New point (6, 5): f = 0.5·6 + 0.5·5 − 3 = 2.5 → positive → class +1. New point (3, 3): f = 0 → exactly on the boundary.

How the support vectors build w. Each support vector gets an importance weight α (alpha). Here αB = αD = 0.25 and every other point has α = 0. Then w = Σ α × class × point = 0.25 × (+1) × (4, 4) + 0.25 × (−1) × (2, 2) = (1, 1) − (0.5, 0.5) = (0.5, 0.5). ✔. And the score of a new point uses only dot products with the support vectors: f(x) = Σ α × class × (support vector · x) + b. For (6, 5): 0.25 × (4·6 + 4·5) − 0.25 × (2·6 + 2·5) − 3 = 11 − 5.5 − 3 = 2.5 ✔. This "only dot products" property is what makes the kernel trick possible (section 4).

3. Real data overlaps: the soft margin and C

Real classes are rarely perfectly separable: a few points sit on the wrong side, or inside the street. Insisting on a perfect street (a hard margin) either fails or produces a razor-thin street twisted around a few odd points. The fix is the soft margin: allow some points to trespass, but charge a fine for each.

The trade-off, in words: minimise ( a term that rewards a wide street ) + C × ( total trespass distance of all the points ).

  • Large C = a heavy fine for trespassing: the street becomes narrow and twisty to keep every training point on the right side (strict, risks overfitting).
  • Small C = a light fine: a wide, relaxed street that tolerates some mistakes (smoother, risks underfitting).

The fine for a point is the hinge loss: max(0, 1 − y·f(x)) where y is +1 or −1 and f is the score.

Situationy × f(x)Hinge loss
True class +1, score +1.7: correct and outside the street1.70
True class +1, score +0.4: correct side, but inside the street0.40.6
True class +1, score −0.5: wrong side−0.51.5
True class −1, score −2: correct and outside20

Points that are safely correct cost nothing; the loss grows the further a point is on the wrong side. Points with a non-zero loss (inside or across the street), plus those exactly on the edge, are the support vectors.

class +1class −1ringed points = support vectors · solid line = boundary · dashed lines = street edges

At small C the street is wide and lots of points are support vectors (they all lean on it). At large C the street shrinks and gets pulled around individual points. 4. When a straight line isn't enough: the kernel trick

What if one class surrounds the other, like a bullseye? No straight line can separate them. But watch what happens if we give each point an extra feature.

A one-dimensional example

Points on a number line: class +1 at x = −1, 0, 1 (in the middle); class −1 at x = −3, −2, 2, 3 (on both sides). One cut can't separate them, because the +1 group is sandwiched. Now add a second feature, x²:

x−3−2−10123
new feature x²9410149
class−1−1+1+1+1−1−1

In the (x, x²) plane every +1 point has x² ≤ 1 and every −1 point has x² ≥ 4. A flat, straight line at x² = 2.5 now separates them perfectly. Mapped back to the original line, that straight cut becomes "the middle zone −1.58 < x < 1.58", a curved boundary in disguise.

The idea: map the data into a higher-dimensional space where a straight line does work, then bring the boundary back. The catch is that mapping to many dimensions explicitly is expensive (sometimes infinite!). The kernel trick avoids ever building those new coordinates. Remember that the SVM only ever needs dot products between points. A kernel function K(x, z) returns the dot product as it would be in the high-dimensional space, computed cheaply from the original points. You just replace every dot product with K.

KernelIn wordsUse
LinearK(x, z) = x · z (no mapping at all)High-dimensional data such as text; when a line is enough
PolynomialK(x, z) = (γ · x·z + 1)d, curves up to degree dInteractions between features
RBF (Gaussian), the usual defaultK(x, z) = exp(−γ · distance²): a similarity score, 1 when the points coincide, fading to 0 as they move apartGeneral-purpose non-linear boundaries

RBF by hand. x = (1, 2) and z = (2, 4): squared distance = (1−2)² + (2−4)² = 1 + 4 = 5.
γ = 0.1 → K = exp(−0.1 × 5) = exp(−0.5) = 0.607 (still fairly similar).
γ = 1 → K = exp(−5) = 0.007 (practically unrelated).
So γ sets how far the "influence" of a point reaches. With RBF the score of a new point is a weighted vote of its similarities to the support vectors: f(x) = Σ α × class × K(support vector, x) + b.

Landmarks. Picture each support vector as a lighthouse casting a circle of influence on the map. A new point is classified by asking how strongly each lighthouse "sees" it, with lighthouses of the +1 team pushing the vote one way and lighthouses of the −1 team the other. A big γ means small, sharp lighthouse beams (the boundary hugs individual points, overfitting); a small γ means broad beams that blur together into a smooth boundary.

Two knobs now control the RBF SVM: C (how strictly to punish mistakes) and γ (how local the influence is). Explore them on three shapes of data:

class +1class −1filled = training · hollow = test · ringed = support vectors · shading = predicted class
  • Circles + linear kernel: hopeless (around 50%). Switch to RBF: near-perfect.
  • Large γ: tiny islands around each training point; training accuracy soars while test accuracy drops (overfitting).
  • Tiny γ: the boundary is almost straight (underfitting).
  • The best pair (C, γ) is found by cross-validation with GridSearchCV, typically on a logarithmic grid such as 0.01, 0.1, 1, 10, 100.

5. SVM in scikit-learn

Our worked example, reproduced (a huge C approximates the hard margin):

from sklearn.svm import SVC

X = [[1, 1], [2, 2], [3, 0], [4, 4], [5, 4], [5, 5]]
y = [-1, -1, -1, 1, 1, 1]

svm = SVC(kernel="linear", C=1e6).fit(X, y)

print(svm.coef_)                 # about [[0.5 0.5]]     -> w
print(svm.intercept_)            # about [-3.]           -> b
print(svm.support_vectors_)      # [[2. 2.] [4. 4.]]     -> only B and D matter
print(svm.n_support_)            # [1 1]                 -> one per class
print(svm.decision_function([[3, 3], [6, 5]]))   # about [0.  2.5]  -> the scores f(x)
print(svm.predict([[6, 5], [1, 0]]))             # [ 1 -1]

These are exactly the numbers from the hand calculation. Now the usual real-world recipe: scale the features (SVMs are distance-based, like KNN), then tune C and γ with cross-validation:

from sklearn.datasets import make_circles, load_breast_cancer
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

# non-linear toy data: one ring inside another
Xc, yc = make_circles(n_samples=300, noise=0.1, factor=0.4, random_state=0)
print(SVC(kernel="linear").fit(Xc, yc).score(Xc, yc))   # poor: about 0.5
print(SVC(kernel="rbf").fit(Xc, yc).score(Xc, yc))      # close to 1.0

# realistic data: tune C and gamma
X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=42)

pipe = Pipeline([("scale", StandardScaler()), ("svm", SVC(kernel="rbf"))])
grid = GridSearchCV(pipe, {"svm__C": [0.1, 1, 10, 100],
                           "svm__gamma": ["scale", 0.001, 0.01, 0.1]}, cv=5)
grid.fit(X_train, y_train)
print(grid.best_params_, grid.score(X_test, y_test))

6. Strengths, limits and real-world use

StrengthsLimits
Excellent on small and medium datasets, especially with many featuresTraining slows down sharply on very large data (roughly quadratic or worse in the number of samples)
The max-margin idea resists overfitting; only support vectors matterNeeds feature scaling and tuning of C and γ
Kernels give flexible non-linear boundariesHard to interpret with a non-linear kernel; no direct probabilities
Linear SVMs are fast and strong for textSensitive to noisy labels when C is large

📝 Text classification

Spam filtering, sentiment and topic tagging: a linear SVM on word features is a classic, hard-to-beat baseline.

🧬 Bioinformatics

Classifying tumours from thousands of gene-expression measurements with only a few hundred patients.

🖼️ Image recognition

Before deep learning, SVMs on hand-crafted image features were the standard for object and pedestrian detection.

✍️ Handwriting

Digit and character recognition with polynomial or RBF kernels was a showcase for SVMs.

🕵️ Anomaly detection

OneClassSVM learns the region where "normal" data lives and flags anything outside it.

🏥 Medical diagnosis

Small, high-dimensional clinical datasets where margins and regularisation keep the model honest.

Key takeaways

  • SVM finds the boundary with the widest margin (street width = 2 ÷ ‖w‖); only the support vectors at the street's edge decide it.
  • The score f(x) = w·x + b: the sign gives the class, and |f| ≥ 1 means "outside the street".
  • Soft margin: C is the fine for trespassing: large C = strict and narrow (overfit risk), small C = relaxed and wide.
  • The kernel trick gets curved boundaries by working as if the data were in a higher dimension, using only kernel similarities. RBF is the default; γ controls how local it is.
  • Always scale features and tune (C, γ) with cross-validation.
  • Great for small/medium, high-dimensional data; slow for huge datasets (use LinearSVC).
